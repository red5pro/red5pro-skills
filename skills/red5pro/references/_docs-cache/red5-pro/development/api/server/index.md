The Red5 Pro Server API can be used to gather statistics for server, application, clients and streams over simple HTTP based REST api calls. The calls can be executed using any standard REST client (for example the [Postman REST client](https://www.postman.com/)). Download the Red5 Pro Server API Postman collection [here](https://www.postman.com/red5-streaming/red5-pro/collection/vg5pqpw/red5-pro-server-api).
