The **Red5 Pro Authentication APIs** provide secure methods for managing user access and controlling authentication workflows within your live streaming applications. These APIs are designed to integrate seamlessly with your existing authentication systems, allowing for custom user verification, session management, and secure access to streams.

- [Round Trip Authentication API Calls](red5-pro-round-trip-authentication-api/): Learn how to implement round-trip authentication mechanisms, ensuring secure communication between your server and client applications.

- [Simple Authentication - Extending the Plugin](red5-pro-simple-authentication-extending-the-plugin/): Explore how to extend the built-in authentication plugin to meet your specific needs, providing a simple yet flexible solution for user access control.
