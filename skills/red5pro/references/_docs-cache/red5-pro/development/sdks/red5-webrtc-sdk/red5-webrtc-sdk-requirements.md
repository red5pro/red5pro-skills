The **Red5 Pro WebRTC SDK** is intended to communicate with a [Red5 Pro Server](https://www.red5.net/), which allows for broadcasting and consuming live streams utilizing [WebRTC](https://developer.mozilla.org/en-US/docs/Web/API/WebRTC_API) and [HLS](https://en.wikipedia.org/wiki/HTTP_Live_Streaming).

## Red5 Cloud

Having an account on [Red5 Cloud](https://cloud.red5.net) is the quickest and easiest way to deploy a Red5 Pro server infrastructure to begin developing an application against.

**[Sign up for free and start using your own Red5 Cloud!](https://cloud.red5.net)**

## Red5 Pro

If you are interested in hosting your own [Red5 Pro Server](https://www.red5.net/) create an account at [https://account.red5.net](https://account.red5.net) and deploy on any cloud service, such as [Amazon Web Services](/docs/red5-pro/users-guide/installation/archive/cloudinstall/awsinstall/).
