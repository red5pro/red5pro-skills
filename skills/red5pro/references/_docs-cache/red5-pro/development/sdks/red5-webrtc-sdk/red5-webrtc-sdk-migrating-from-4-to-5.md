# Migrating from `4.0.0` to `5.0.0`

The `5.0.0` release of the Red5 Pro WebRTC SDK mainly focused on internal bug fixes and compliancy changes to match updates to the Red5 Pro Server v5.0.0 release.

To see updates that may cause possible issues in integration with your webapp(s), please refer to the *CHANGES* documentation distributed with the Red5 Pro WebRTC SDK available from your [Red5 Pro Account](https://account.red5.net/login).
