This section describes using the **Red5 Pro WebRTC SDK** browser install to create sessions for a ingest and egress stream using [WHIPClient](#whip-client) and [WHEPClient](#whep-client), respectively.

## WHIP/WHEP

Please refer to the [WHIP/WHEP documentation](/docs/red5-pro/development/sdks/red5-webrtc-sdk/red5-webrtc-sdk-whip-whep-overview/) for information about utilizing the `WHIPClient` and `WHEPClient` to set up broadcast and playback sessions, respectively.
