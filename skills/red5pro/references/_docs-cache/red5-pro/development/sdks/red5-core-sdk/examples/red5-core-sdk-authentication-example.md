The Authentication example shows how to use authentication data for interacting with Red5 Pro Server. The only requirements are to provide authentication data in the `ServerDescription` structure. Note that unless you have [authentication](/docs/special/authplugin/overview/) configured on your Red5 Pro Server, authentication data will be ignored by the server.
