This use case mixes a large number of live streams together into a single output stream using a set of stacked mixers. Some mixers process the client-published streams while others use the mixed streams published by other mixers. This use case is diagramed in Figure 1 below. 

Possible scenarios include control rooms displaying a mix of a large set of camera streams for large video walls. For video wall solutions, the live streams are managed remotely by an editor that dynamically adds, removes, mutes, or unmutes source streams as needed.
