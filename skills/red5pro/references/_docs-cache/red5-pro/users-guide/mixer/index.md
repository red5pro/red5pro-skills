Red5 Pro provides a powerful mixer for advanced real-time video and audio processing: Brew Mixer. As a server-side Multipoint Control Unit (MCU), Brew Mixer integrates directly with the Red5 Pro server to deliver native performance and flexible control.

Powered by the Cauldron Media Engine, Brew Mixer enables dynamic video and audio mixing within the Red5 Pro environment. Through its REST API, developers can easily create complex layouts, manage audio pan and volume controls, and integrate these capabilities into external applications.
