You can use the Red5 Pro WebRTC SDK to develop your **browser-based** application. [The Red5 Pro HTML5 Streaming Example App](https://github.com/red5pro/streaming-html5) contains a simple project with a number of examples that can be used for testing and reference with the Red5 Pro WebRTC SDK.

The app is also included as a webapp with the server release for developer testing, and can be accessed at `https://<your_server_ip>/webrtcexamples/` (or `http://localhost:5080/webrtcexamples/` if you are running the server locally).

You will find some more details on the [Red5 Pro WebRTC SDK here](/docs/development/webrtc/installation/)
