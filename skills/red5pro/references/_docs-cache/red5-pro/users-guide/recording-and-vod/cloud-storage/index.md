Red5 Pro supports integration with various cloud storage services, allowing you to store, manage, and access recorded streams or video-on-demand (VOD) content efficiently. Whether you're using AWS, GCP, Azure, or another provider, Red5 Pro's flexible architecture and cloud storage plugin make it easy to configure your preferred storage solution to fit your workflow.

This section provides detailed guidance on configuring, customizing, and managing cloud storage for recorded streams, including plugin settings, server configuration, and file management.
