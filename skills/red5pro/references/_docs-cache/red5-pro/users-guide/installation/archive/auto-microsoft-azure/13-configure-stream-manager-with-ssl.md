If you want to publish via WebRTC, or iOS, you must set up the Stream Manager with a valid SSL certificate and use the Stream Manager SSL Proxy feature.  Please refer to [this document](/docs/red5-pro/users-guide/installation/ssl/red5-pro-ssl-prerequisites/) to configure SSL on your Red5 Pro Stream Manager.
