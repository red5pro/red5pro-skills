Connect to vSphere using a Web browser or vSphere client, and create a new Ubuntu 20.04 VM to run Stream Manager, MySQL, and Terraform. For a small- to medium-sized environment, two CPUs and 16G memory should be sufficient. For larger environments, you will want a larger VM, specifically more memory for the Red5 Pro JVM heap allocation.
