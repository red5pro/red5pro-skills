The majority of the [WebRTC testbed Stream Manager examples](https://github.com/red5pro/streaming-html5/tree/master/src/page/sm-test) are configured to run via SSL proxy because of the nature of WebRTC operations.

Basic publish and subscribe examples:

* [Publish - Stream Manager Proxy](https://github.com/red5pro/streaming-html5/tree/master/src/page/sm-test/publishStreamManagerProxy)
* [Subscribe - Stream Manager Proxy](https://github.com/red5pro/streaming-html5/tree/master/src/page/sm-test/subscribeStreamManagerProxy)

*Note: the `streaming-html5` examples testbed is included with the Red5 Pro server distribution, and can be accessed via your stream manager at `https://your.server.url/webrtcexamples/`.*
