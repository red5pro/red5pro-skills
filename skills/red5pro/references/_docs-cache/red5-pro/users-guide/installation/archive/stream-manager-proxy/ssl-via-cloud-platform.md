If you want to load-balance multiple Stream Managers, then you can also use the [AWS](/docs/red5-pro/users-guide/installation/archive/auto-aws/optional-load-balance-multiple-stream-managers/), [Azure](/docs/red5-pro/users-guide/installation/archive/auto-microsoft-azure/12-optional-load-balance-multiple-sms/), [Digital Ocean](/docs/red5-pro/users-guide/installation/archive/auto-digital-ocean/09-optional-load-balance-stream-managers/), or [Google Cloud](/docs/red5-pro/users-guide/installation/archive/auto-google-cloud/stream-manager-configuration/#optional-load-balance-multiple-stream-managers) load balancers to proxy the SSL Certificate. See the platform-specific doc links for details.
