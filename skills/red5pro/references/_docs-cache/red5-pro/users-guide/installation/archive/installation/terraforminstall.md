# Installing Red5 Pro using public Terraform Modules

Red5 Pro clusters can be installed on Cloud Platforms using our public Terraform Modules. These modules are available on the [Red5 Pro Terraform Registry](https://registry.terraform.io/modules/red5pro/red5pro). We recommend using Terraform as it helps ensure the installations are proper and allows you to more easily manage your Red5 Pro clusters. Documentation for each of the modules is available on the Terraform Registry.

### AWS Terraform Module
[Red5 Pro Terraform Registry - AWS Terraform Module](https://registry.terraform.io/modules/red5pro/red5pro/aws/latest)

### Digital Ocean Terraform Module
[Red5 Pro Terraform Registry - Digital Ocean Terraform Module](https://registry.terraform.io/modules/red5pro/red5pro/digitalocean/latest)

### OCI Terraform Module
[Red5 Pro Terraform Registry - OCI Terraform Module](https://registry.terraform.io/modules/red5pro/red5pro/oci/latest)
