# Quick Start Guides

Since Red5 Pro is a full-stack development platform you actually need to set up the server first before you build your client-side applications. We created this document to quickly get you up and running with the basics.

---

## Server

Red5 Pro server acts as a hub, enabling connections between various end-points including our mobile SDKs, iOS and Android, and browser-based clients via WebRTC or HLS.

__[Red5 Pro Server Quick Start](/docs/red5-pro/users-guide/installation/archive/auto-aws-wav/ubuntuinstall/)__

## Mobile Streaming SDKs

Building live streaming apps for iOS and Android can be a major pain if you’re starting from scratch. We built these SDKs to seamlessly integrate with our server, giving you more time to build out the functionality of your app.
