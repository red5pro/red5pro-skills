_From: Upgrading from Red5 Pro v13 to v15_

## Support

If you encounter issues during the upgrade process:

1. Check the [Red5 Pro Known Issues](/docs/red5-pro/resources/red5-pro-known-issues/) page
2. Review the [Troubleshooting Guide](/docs/red5-pro/users-guide/troubleshooting-and-best-practices/)
3. Contact Red5 Pro support: [support@red5.net](mailto:support@red5.net)
4. Include your Red5 Pro server logs: `/usr/local/red5pro/log/red5.log`
