_From: Upgrading from Red5 Pro v14 to v15_

## Support

If you encounter issues during the upgrade:

1. Check [Red5 Pro Known Issues](/docs/red5-pro/resources/red5-pro-known-issues/)
2. Review [Troubleshooting Guide](/docs/red5-pro/users-guide/troubleshooting-and-best-practices/)
3. Contact support: [support@red5.net](mailto:support@red5.net)
4. Include logs: `/usr/local/red5pro/log/red5.log`
