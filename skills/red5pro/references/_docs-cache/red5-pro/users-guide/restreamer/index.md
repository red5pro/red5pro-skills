The Restreamer Plugin integrates with disparate video sources, servers, and services.

* File (publish a video file as a live stream)
* IP Cam (pull RTSP internet camera sources)
* MPEG-TS (video encoders, routers, etc)
* SRT (SRT-enabled devices)
* RTMP (pull from or push to other RTMP servers, including Red5 Pro, social media platforms, etc)
* Zixi (integrate directly with Zixi Broadcaster, both push and pull)

Plugin configuration options are located in the `conf/restreamer-plugin.properties` configuration file.
