Red5 Cloud provides powerful **Software Development Kits (SDKs)** that help developers build custom applications with ease. The SDKs allow you to integrate Red5 Cloud's advanced streaming features into your own platforms, whether you're developing for web, mobile, or other devices.

- [Red5 Core SDK](red5-core-sdk/): The **Red5 Core SDK** is the foundational toolkit for building live streaming applications. It provides the core capabilities for streaming video and audio, as well as support for various protocols, including RTMP and HLS. Developers can use the Core SDK to create customized live-streaming solutions tailored to their specific needs, while leveraging Red5 Cloud's robust cloud infrastructure.

- [Red5 Pro WebRTC SDK](red5-pro-webrtc-sdk/): The **Red5 Pro WebRTC SDK** is designed for real-time communication and low-latency video streaming. Ideal for applications requiring instant, interactive communication (e.g., video chat, online gaming, and live broadcasting), this SDK enables the integration of WebRTC protocols for fast, high-quality, and secure streaming. It's perfect for creating real-time, peer-to-peer applications on web and mobile platforms.

- [Conference SDK](conference-sdk/): The **Red5 Pro Conference SDK** is a powerful, professional-grade toolkit for building multi-party video conferencing applications. It handles room management, media streaming via WHIP/WHEP, WebRTC statistics, interactive features, and advanced capabilities like virtual backgrounds and local recording.

- [iOS SDK](ios-sdk/): The **Red5 Pro iOS SDK** (`Red5WebRTCKit`) enables native iOS applications to publish and subscribe to live streams over WebRTC. It handles ICE negotiation, codec selection, camera/microphone capture, and license validation out of the box. Includes bite-sized examples covering minimal publish, minimal subscribe, audio-only streaming, custom video settings, and live camera controls.

- [Android SDK](android-sdk/): The **Red5 Android SDK** enables native Android applications to publish and subscribe to live streams over WebRTC with sub-second latency. Built on the WHIP/WHEP protocol stack, the SDK handles ICE negotiation, camera/microphone capture, and license validation — compatible with both Red5 Cloud (Stream Manager) and standalone Red5 Pro servers. Supports conferencing, chat integration via PubNub, real-time stats collection, and Picture-in-Picture mode.

- [Backend SDK](backend-sdk/): The **Red5 Backend SDKs** allow your server to generate secure access tokens for video conferences and chat messaging. Available for Node, Java, and Go. Tokens let users join live video rooms and communicate in chat without exposing master credentials on the client.
