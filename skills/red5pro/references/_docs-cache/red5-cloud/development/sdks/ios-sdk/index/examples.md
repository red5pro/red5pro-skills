_From: iOS SDK_

## Examples

Each example is a self-contained iOS app demonstrating one specific feature. Copy the two files (`Config.swift` + the example file) into a fresh Xcode project, edit `Config.swift` with your server details, and run.

- [Minimal Publish](minimal-publish/) — the fewest lines needed to go live
- [Minimal Subscribe](minimal-subscribe/) — the fewest lines needed to receive a stream
- [Audio Only](audio-only/) — publish or subscribe with video disabled
- [Custom Video Settings](custom-video-settings/) — configure resolution, frame rate, and bitrate
- [Camera Controls](camera-controls/) — flip camera, mute/unmute video and audio while live
