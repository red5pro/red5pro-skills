Build low-latency live streaming apps with the Red5 Android SDK. See the [API Reference](api-reference/) for a complete list of classes, interfaces, and methods. Stream video using WHIP, and subscribe (play) streams via WHEP. Compatible with both Red5 Pro Cloud (Stream Manager) and standalone Red5 Pro servers.
