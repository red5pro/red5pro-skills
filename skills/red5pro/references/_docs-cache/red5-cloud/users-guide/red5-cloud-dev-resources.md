## Dev Resources Overview

The Dev Resources Page provides quick access to code that you can use for publishers and subscribers. The code is generated for your account. You can copy the code and use it in your application.

## Stream Manager and Admin User

![Stream Manager and Admin User](/_images/red5-cloud/users-guide/dev-resources-1.png)

The Stream Manager URL is provided (1). The Stream Manager is the central hub for managing your Red5 Cloud deployments. If you have a Startup or higher plan, the Admin User (2) and the Admin Password (3) are provided for the Stream Manager.  These can be used to get a JW Token for use with the [Stream Manager API](/docs/red5-cloud/development/api/stream-manager-2.0/)

## WebRTC

![WebRTC](/_images/red5-cloud/users-guide/dev-resources-2.png)
